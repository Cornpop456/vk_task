# PubSub - Сервис подписок на основе subpub

## Описание

PubSub - это сервис подписок, реализованный на языке Go с использованием gRPC и библиотеки subpub. Сервис позволяет:

1. Подписываться на события по ключу (топику)
2. Публиковать события для всех подписчиков по ключу (топику)

## Архитектура

Проект включает в себя следующие компоненты:

- **subpub**: базовая библиотека для работы с событиями и подписками
- **api/proto**: описание gRPC API для взаимодействия с сервисом
- **server**: реализация gRPC-сервера, обрабатывающего запросы клиентов
- **client**: клиентская библиотека для работы с сервисом
- **examples**: демонстрационные примеры использования сервиса

## Используемые паттерны проектирования

### Паттерн Publish/Subscribe
Основа сервиса - классический паттерн Publish/Subscribe, реализованный в пакете `subpub`. Он обеспечивает слабое связывание между издателями и подписчиками, позволяя компонентам взаимодействовать без прямых зависимостей.

### Graceful Shutdown
Сервис реализует механизм корректного завершения работы (Graceful Shutdown):
- Перехват сигналов операционной системы (SIGINT, SIGTERM)
- Вызов `GracefulStop()` для gRPC-сервера, который позволяет завершить текущие запросы
- Контекст с таймаутом для ограничения времени завершения
- Корректное закрытие всех ресурсов системы (каналы, подписки, обработчики сообщений)

### Worker Queue
Механизм асинхронной обработки сообщений использует буферизованный канал как очередь сообщений с отдельной горутиной-обработчиком, что позволяет распараллелить публикацию и доставку сообщений.

### Dependency Injection
Компоненты системы слабо связаны и используют внедрение зависимостей через интерфейсы:
- `SubPub` интерфейс абстрагирует конкретную реализацию системы публикации/подписки
- `Subscription` интерфейс обеспечивает управление подписками

## Установка и запуск

### Предварительные требования

- Go версии 1.21 или новее
- Компилятор Protocol Buffers (protoc)

### Сборка

```bash
# Клонирование репозитория
git clone https://github.com/Cornpop456/vk_task.git
cd vk_task

# Загрузка зависимостей
go mod download
```

### Запуск сервера

```bash
go run cmd/main.go
```
## Конфигурация

Сервис можно настроить с помощью следующих переменных окружения:

- `PUBSUB_PORT` - порт для gRPC-сервера (по умолчанию 50051)
- `PUBSUB_MAX_CONNECTIONS` - максимальное количество одновременных соединений (по умолчанию 100)
- `PUBSUB_LOG_LEVEL` - уровень логирования: debug, info, warn, error (по умолчанию "info")
- `PUBSUB_LOG_FILE` - путь к файлу для сохранения логов (если не указан, логи выводятся в stdout)

## Запуск демонстрационного примера

Для запуска примера выполните следующие шаги:

1. Убедитесь, что сервер PubSub запущен:
   ```bash
   go run cmd/main.go
   ```

2. В отдельном терминале запустите демонстрационный пример:
   ```bash
   go run examples/pubsub_example.go
   ```
## API gRPC

### Доступные методы

#### Subscribe - подписка на события

```proto
rpc Subscribe(SubscribeRequest) returns (stream Event);
```

#### Publish - публикация события

```proto
rpc Publish(PublishRequest) returns (google.protobuf.Empty);
```
